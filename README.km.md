# Tempo — កំណត់ត្រា និងភារកិច្ចប្រចាំថ្ងៃ

កម្មវិធីរៀបចំផែនការផ្ទាល់ខ្លួន ដែលដំណើរការលឿន និងប្រើបានដោយគ្មានអ៊ីនធឺណិត៖
ភារកិច្ចមានកម្រិតអាទិភាព ភារកិច្ចរង និងការរំលឹក កំណត់ត្រាចម្រុះពណ៌ជាមួយបញ្ជីត្រួតពិនិត្យ
ប្រតិទិន ស្ថិតិ ប្រភេទ ស្បែកភ្លឺ/ងងឹត និងចំណុចប្រទាក់ជាភាសាអង់គ្លេស/ខ្មែរ។

សរសេរដោយ HTML + CSS + JavaScript modules សុទ្ធ។ **មិនចាំបាច់ build មិនប្រើ framework មិនប្រើ npm ឡើយ។**

## របៀបដំណើរការ

កម្មវិធីរុករក (browser) មិនផ្ទុក JavaScript modules ពី `file://` ទេ ដូច្នេះត្រូវបើកថតឯកសារតាមរយៈ server៖

```bash
cd tempo
python3 -m http.server 8000
# បើក http://localhost:8000
```

អាចដាក់លើ static hosting ណាមួយក៏បាន (Firebase Hosting, Netlify, GitHub Pages)។ នៅលើ HTTPS ឬ
localhost ឯកសារ service worker (`sw.js`) នឹងរក្សាទុកកម្មវិធីក្នុង cache ដើម្បីឱ្យបើកបានដោយគ្មានអ៊ីនធឺណិត
ហើយអាចដំឡើងជាកម្មវិធី PWA បាន។

## ការកែប្រែដែលប្រើញឹកញាប់

| ខ្ញុំចង់… | កែនៅ |
|---|---|
| ប្តូរពណ៌ម៉ាក | `css/tokens.css` → `--primary-solid` និង `--brand-2` (ឬជ្រើសពណ៌សំខាន់ក្នុង ការកំណត់) |
| ប្តូរពណ៌របៀបងងឹត | `css/tokens.css` → ប្លុកងងឹតទាំងពីរ (ត្រូវរក្សាឱ្យដូចគ្នា) |
| ប្តូរពុម្ពអក្សរ | តំណពុម្ពអក្សរក្នុង `index.html` + `--font-display` / `--font-body` ក្នុង `tokens.css` |
| ប្តូរភាពមូលនៃជ្រុង / ស្រមោល | `--radius-*` និង `--shadow-*` ក្នុង `tokens.css` |
| ធ្វើឱ្យចលនាលឿន/យឺតជាងមុន | `--dur-fast`, `--dur`, `--dur-slow` ក្នុង `tokens.css` |
| កែផ្ទាំងគ្រប់គ្រង (dashboard) | `js/pages/dashboard.js` (HTML) + ផ្នែក "Dashboard" ក្នុង `css/pages.css` |
| កែរូបរាងកាតភារកិច្ច | `js/ui/taskCard.js` + "Task card" ក្នុង `css/components.css` |
| កែរូបរាងកាតកំណត់ត្រា | `js/ui/noteCard.js` + "Note card" ក្នុង `css/components.css` |
| បន្ថែមវាលថ្មីឱ្យភារកិច្ច | `createTask()` ក្នុង `js/core/models.js` បន្ទាប់មកទម្រង់ក្នុង `js/features/tasks.js` |
| ប្តូរឈ្មោះប៊ូតុង ឬសារ | `js/core/i18n.js` |
| ប្តូរ breakpoints / ប្លង់លើទូរសព្ទ | `css/layout.css` (shell) និងផ្នែក "Responsive" ក្នុង `css/pages.css` |
| បន្ថែមទំព័រថ្មី | បង្កើត `js/pages/mypage.js` បន្ថែមវាទៅ `js/pages/index.js`, `ROUTES` ក្នុង `router.js`, `NAV` ក្នុង `layout/shell.js` |

## របៀបដែលទិន្នន័យដំណើរការ

- ទិន្នន័យទាំងអស់ស្ថិតក្នុង object តែមួយ (មើល `createEmptyState()` ក្នុង `models.js`)៖
  `{ meta, profile, settings, tasks[], notes[], categories[], reminders[] }`។
- ទំព័រនានាមិនផ្លាស់ប្តូរទិន្នន័យដោយផ្ទាល់ទេ។ ពួកវាហៅ `actions.*` ក្នុង `store.js`
  ដែលរក្សាទុកដោយស្វ័យប្រវត្តិក្រោយ 250 ms (ហើយរក្សាទុកភ្លាមៗ ប្រសិនបើបិទផ្ទាំង)។
- មុនពេល នាំចូល លុបទាំងអស់ ឬផ្ទុកទិន្នន័យគំរូ កម្មវិធីរក្សាទុកច្បាប់បម្រុងជាមុនសិន។ ការកំណត់ → ទិន្នន័យ →
  *ស្តារការបម្រុងទុក* នឹងយកវាមកវិញ។ ការលុបនីមួយៗបង្ហាញសារ toast ដែលមានប៊ូតុង **មិនធ្វើវិញ**។
- **Sync ទៅ cloud នៅថ្ងៃក្រោយ៖** សរសេរអាដាប់ទ័រមួយដែលមាន `load()`, `save(state)`, `backup(state)`,
  `loadBackup()` (ឧ. ប្រើ Supabase ឬ Firebase) ហើយ export វាជា `storage` ពី
  `js/core/storage.js`។ ភារកិច្ច/កំណត់ត្រានីមួយៗមាន `id`, `createdAt` និង `updatedAt` រួចហើយ
  សម្រាប់ការបញ្ចូលទិន្នន័យចូលគ្នា (merge)។

## ផ្លូវកាត់ក្តារចុច

`Ctrl/Cmd + K` ឬ `/` ស្វែងរក · `N` ភារកិច្ចថ្មី · `1`–`7` ប្តូរទំព័រ · `Ctrl + Enter` រក្សាទុកទម្រង់ ·
`Esc` បិទ · គ្រាប់ចុចព្រួញ ផ្លាស់ទីរវាងថ្ងៃក្នុងប្រតិទិន។
